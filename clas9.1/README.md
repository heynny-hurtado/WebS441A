# Tienda Intergaláctica

Proyecto del taller práctico de JavaScript usando HTML semántico, CSS y JavaScript.

## Estructura de archivos

- `index.html`: estructura semántica de la página.
- `css/styles.css`: estilos y diseño adaptable a móviles.
- `js/script.js`: ejercicios de variables, condicionales, bucles, funciones, objetos y clases.

## Cómo ejecutarlo

1. Descomprime el archivo ZIP.
2. Abre la carpeta `tienda_intergalactica` en Visual Studio Code.
3. Abre `index.html` en un navegador. También puedes usar la extensión Live Server.
4. Para ver los `console.log`, abre las herramientas del navegador con F12 y entra a la pestaña Console.

## HTML semántico usado

El documento utiliza `header`, `nav`, `main`, `section`, `article`, `form`, `label`, `button`, `output` y `footer`.
